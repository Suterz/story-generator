# Whole-film and reviewer development

The opening configuration remains provisional. Use `--body-instruction
advancing-v1` for an outline with an explicit new inference in each
chapter, and `advancing-bound-v2` to add a narrow literal comparison check.
Neither is a production default. The exact duplicate guard checks text, not
panel similarity. A highlight or a new diagram is not assumed to teach
something new by itself.

`body_progress.py RUN` measures repetition, panel holds and captions on a
delivered film. `body_assembly.py OPENING BODY OUTPUT --body-offset SECONDS`
is a controlled screening utility, not the ordinary production path. It
checks decoded video frames and audio samples for the complete normalized
prefix, so two screening bodies can be compared with that same opening.

`discovery_review.py` derives expectations from the objective and source
before opening any clip. It never uses the archive's supplied windows.
Both timed observations and the original export hash are retained. A
model quote only receives a timestamp when it occurs exactly once in the
delivered transcript; ambiguous or missing evidence is uncertain. These
are development arms; the existing timed-assertion fixtures remain a
separate evaluator-guided control. Uniformly sampled frames can miss a
short reveal, and transcript localization does not verify a visual-only
fault. Never infer qualification from these diagnostics.

## Independent qualification handoff

Use the opaque candidate IDs and source packets for labeling. The synthetic
control pool is a starting point; a custodian must add representative
documentary, illustrative and natural failure cases before claiming broad
coverage. A seeded alteration does not establish the publishability of the
other clip. Label the whole export independently, with a reason, actual
defect and interval for bad cases. Keep labels outside reviewer storage.
Use `lock_qualification.py` to commit the labels and MP4 hashes, freeze the
reviewer version and score only after predictions are locked. Keep matched
variants grouped. The distinct five sealed briefs need an independent
custodian and a predeclared eligibility rule. They are not a development set.
